LoLDB 監査修正の検証記録

【結論】

REVIEW-001〜009の修正を実施し、パッチ16.21.1の173体・264ロールを再検証した。対面統計とロール別対面行列は作業前と一致する。図鑑は通常SR用225件。

【修正と確認】

1. ルーン所属を公式辞書で照合し、全ロールのサブパス空欄と英語シャードを補正。欠損時の固定ルーン表示を廃止。
2. RSCをJSONとして復号し、配列の境界内で抽出。全264ロールで完成品3枠を取得。カシオペアの靴は保存データ・全ビルドパターン・描画から除外。
3. モード別クローンと内部ペットを除外し、合成リンクを整理。変身後完成品を保持。正当な同名の黒槍2件はカリスタ用・サイラス用としてIDと専用条件で区別。
4. スキル説明を改行付きのプレーンテキストに正規化。動的テキスト・属性・URL・画像URL・CSS列挙値を分けて描画。
5. 立ち回り見出しの重複を解消し、全ロールの属性接頭辞と個別JSONを同期。新規3ロールの根拠付き補完を登録。再統合と旧補完スクリプトの実行入口で実測・手動補完を保持。
6. ピックをIDで管理し、公式名・通称・英語・かな検索を統一。既存の手動選択方針を保持。
7. wikiキャッシュをリポジトリ内へ変更し、旧キャッシュは削除しない。サステイン解析ではslotを優先して読み、既存の公開スキーマを保持。
8. 未使用の分割JSONと推定処理を配布から除去し、HTML内の重複を削減。省データ・低速回線・オフラインでは画像先読みを停止。
9. HYBRIDフィルター、モーダルの戻る・進む、ダイアログ属性、フォーカス・背面スクロール制御を追加。READMEとデータ仕様を現行化。

【検証】

- Pythonの31テスト、生成アプリのNode関数テスト、パッチ・個別JSON・キャッシュ検証が通過。
- 全173体をメモリ上で再統合し、ロール別の対面統計、コンボ、立ち回り、スキル順と取得表が保持されることを確認。
- リモートの実ブラウザーで実装ブランチの生成HTMLを検証。検索、HYBRID、靴非表示、Lux ADC、モーダルと合成ツリーの履歴、背面ロック解除が通過。
- 375・390・430px幅でピック画面の横はみ出しがないことを確認。ローカルのブラウザー操作はWork設定で無効のため使用していない。
- 容量基準は変更前HTML 6,695,546バイト、ZIP 2,002,210バイト。修正時点で約27%・60%削減。更新履歴追加による小幅な変動を含む最終値は生成物で確認する。

【追加調査の限界】

Lux ADC・Sion MID・Tristana MIDのスキル順は対象パッチのOP.GGから取得。取得表は掲載されたLv1〜15のみ。文章・コンボはMobalyticsの対象ロール別ガイドを短く要約し、現在パッチ対応は未検証として出典を表示する。未取得レベルを固定規則で補完しない。
